# Signaler un problème de sécurité

N'ouvrez **pas** d'issue publique contenant une clé API, un secret actif, un
jeton, des données personnelles ou les détails exploitables d'une vulnérabilité
non corrigée.

Pour un problème qui concerne ce dépôt, utilisez de préférence la fonction
**Report a vulnerability** dans l'onglet **Security** de GitHub, si les avis de
sécurité privés sont activés. Sinon, contactez le mainteneur par un canal privé
approprié avant toute publication.

Indiquez, sans inclure de secret : la version ou le commit concerné, les étapes
de reproduction minimales et l'impact potentiel.

Les rapports générés peuvent contenir des chemins de fichiers et du contexte de
code. Vérifiez leur contenu avant de les diffuser publiquement.

Ce projet n'établit pas de délai garanti de traitement des signalements.
